# Project Statement

## Problem Statement

Students often make small daily payments for food, transportation, shopping and other activities. When these expenses are not recorded properly, it becomes difficult to understand where money is being spent and whether the monthly budget is being followed.

The Student Expense & Budget Tracker provides a simple Python-based solution for recording expenses and monitoring spending.

## Scope

The project focuses on personal expense tracking for students. It records individual expenses, organizes them by category, calculates spending summaries and compares total spending with a monthly budget.

The current version is a console-based application using local files for data storage.

## Target Users

- College students
- Students living away from home
- Students who want to monitor daily spending
- Beginners who want a simple personal budgeting tool

## High-Level Features

1. Expense Management
   - Add expense
   - View expenses
   - Edit expense
   - Delete expense

2. Expense Analysis
   - Search by category
   - Calculate total spending
   - Calculate category-wise spending

3. Budget Management
   - Set monthly budget
   - Check total spending
   - Check remaining budget

## Inputs

- Expense amount
- Expense category
- Expense description
- Monthly budget
- Menu choices

## Outputs

- Saved expense records
- Expense list
- Category-wise summary
- Total spending
- Budget status
