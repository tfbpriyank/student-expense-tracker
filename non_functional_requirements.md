# Non-Functional Requirements

## 1. Usability

The application uses a simple menu-driven interface so that a student can operate it without technical knowledge.

## 2. Reliability

The application handles missing or invalid input and can start even when no previous expense file exists.

## 3. Maintainability

The program is divided into separate Python modules based on their responsibilities.

## 4. Error Handling

Invalid numerical input and missing data files are handled using validation and exception handling.
